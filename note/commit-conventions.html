提交 Commit 的约定

2026年11月8日

每次提交必须使用一个类型前缀

feat
引入新功能（对应语义化版本的 MINOR）
fix
修复 Bug（对应语义化版本的 PATCH）
docs
仅修改文档（Documentation）
style
修改代码格式（不影响代码运行，如空格、分号、缩进等）
refactor
代码重构（既不修复 bug 也不添加新功能）
perf
性能优化（Performance）
test
增加或修改测试用例
build
影响构建系统或外部依赖的更改（webpack、npm 等）
ci
持续集成配置文件和脚本的变动
chore
构建过程或辅助工具的变动（不修改源码和测试）
revert
回滚到上一个版本
